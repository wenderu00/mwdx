# Perfil do dono dos repositórios

Lido por todos os especialistas e pelo estrategista. É o que define o que "bom"
significa para as notas e os achados.

Este é um exemplo. Para usar o seu, copie para `~/.mwdx/perfil.md` (ou
`$MWDX_HOME/perfil.md`) e edite: se esse arquivo existir, ele é usado no lugar deste.

- **Quem**: desenvolvedor(a) em início de carreira, com repositórios de estudo e
  projetos pessoais no GitHub.
- **Objetivo de carreira**: vagas de desenvolvedor **backend/fullstack**.
- **O que o portfólio precisa provar**: domínio de backend (modelagem, APIs,
  persistência, testes automatizados, arquitetura em camadas/hexagonal, CI/CD,
  deploy), capacidade de explicar decisões técnicas e entregar projetos completos.
- **Público de quem avalia**: recrutadores (leem só o README, em ~30 segundos) e
  engenheiros (abrem o código, os testes e o histórico).
- **Contexto dos repositórios**: dezenas de repos de anos diferentes. Muitos antigos são
  de bootcamp/disciplina; os recentes são os que mais representam o nível atual.
  Nem todo repo precisa virar vitrine — "arquivar" ou "tornar privado" é uma
  recomendação válida.
- **Não sugerir**: trocar de linguagem ou framework só por moda; reescritas
  completas de projetos acadêmicos encerrados.
